# Анализ кредитных займов Lending Club

> Учебный проект по статистическому анализу данных о потребительских кредитах.

В ноутбуке исследуются факторы, связанные с процентной ставкой, просрочками и размером ежемесячного платежа. Анализ выполнен на случайной выборке из 100 000 наблюдений и включает проверку гипотез и сравнение корреляционных методов.

## Что внутри

`p_code2.ipynb` содержит:

- сравнение процентных ставок у погашенных и проблемных займов;
- сравнение числа просрочек для кредитных рейтингов A и B;
- сравнение годовых доходов владельцев жилья и арендаторов;
- проверку гипотез параметрическими t-тестами и критерием Манна—Уитни;
- анализ связей методом Пирсона, Спирмена и Кендалла;
- текстовые интерпретации результатов на русском языке.

## Данные

Ноутбук ожидает исходный CSV-файл `accepted_2007_to_2018Q44.csv` в текущей рабочей директории. Файл данных не включён в репозиторий: получите датасет Lending Club из источника, предусмотренного вашим курсом, и положите его рядом с ноутбуком.

Из исходных данных выбираются нужные признаки, после чего фиксированным `random_state=42` формируется выборка из 100 000 строк.

## Запуск

1. Установите Python 3 и Jupyter Notebook или JupyterLab.
2. Установите библиотеки:

   ```bash
   pip install pandas numpy scipy statsmodels jupyter
   ```

3. Поместите `accepted_2007_to_2018Q44.csv` рядом с ноутбуком.
4. Откройте и выполните `p_code2.ipynb`.
